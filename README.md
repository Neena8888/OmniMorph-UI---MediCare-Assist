# OmniMorph UI — MediCare Assist

> Multimodal, context-aware adaptive patient registration and clinical triage portal designed with human-computer interaction (HCI) ergonomics and accessibility standards.

## Overview
OmniMorph UI demonstrates real-time interface adaptation driven by user modality, ambient conditions, and cognitive requirements. Built with zero runtime dependencies using vanilla web standards.

## Key Features
- **Multimodal Interaction:** Seamless hands-free voice command routing and real-time speech dictation via the Web Speech API alongside standard pointer/keyboard inputs.
- **Cognitive Load Optimization:** Minimalist focus view suppressing non-critical interface components during clinical intake.
- **Accessibility & Ergonomics:** High-contrast palette compliant with WCAG 2.1 AAA criteria (>4.5:1 ratio) and scalable typography for visual impairment.
- **Ambient Light Sensing:** Simulated environmental adaptation responding to ambient luminosity changes.

## Technology Stack
- Semantic HTML5
- CSS3 Custom Properties
- JavaScript (Web Speech API)
